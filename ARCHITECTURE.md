## Data Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           INFERENCE LOOP (~10-15 Hz)                        │
│                                                                             │
│   RASPBERRY PI                              LAPTOP (GPU)                    │
│   ────────────                              ────────────                    │
│                                                                             │
│   ┌─────────┐        ┌─────────┐         ┌─────────┐         ┌─────────┐  │
│   │ Camera  │  RGB   │ Encode  │  HTTP   │ SmolVLA │ action  │  Send   │  │
│   │  Frame  │───────►│ Base64  │────────►│  GPU    │────────►│  Back   │  │
│   │ 640x480 │        │  + JSON │  POST   │ Infer   │  JSON   │         │  │
│   └─────────┘        └─────────┘         └─────────┘         └────┬────┘  │
│       │                                                           │        │
│       │ 10ms            20ms                60-80ms              10ms      │
│       │                                                           │        │
│       │              ┌─────────┐                                  │        │
│       │              │  Robot  │◄─────────────────────────────────┘        │
│       └─────────────►│ Execute │                                           │
│         next frame   │ Action  │                                           │
│                      └─────────┘                                           │
│                          20ms                                              │
│                                                                             │
│              Total Loop: ~100-120ms = 8-10 Hz                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Software Components

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   LAPTOP (laptop_server.py)           PI (pi_client.py)                    │
│   ─────────────────────────           ─────────────────                    │
│                                                                             │
│   1. Load SmolVLA model               1. Connect to robot arm              │
│   2. Start FastAPI server             2. Connect to camera                 │
│   3. Wait for requests                3. Loop:                             │
│   4. Receive image + state               a. Capture frame                  │
│   5. Run inference (GPU)                 b. Get joint positions            │
│   6. Return action                       c. Send to laptop                 │
│                                          d. Receive action                 │
│                                          e. Execute on robot               │
│                                                                             │
│   Endpoint:                           Connects to:                         │
│   POST /predict                       http://<laptop-ip>:8000/predict      │
│   {image, state, task}                                                     │
│   -> {action}                                                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
